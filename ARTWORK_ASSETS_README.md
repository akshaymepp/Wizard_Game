# Wizard Premium Artwork Pack

This pack contains original AI-generated fantasy reference artwork for the Wizard game.

## Included runtime image assets
- `portrait_rahul.png`
- `portrait_nithin.png`
- `portrait_arun.png`
- `portrait_vishnu.png`
- `wizard_card_art.png`
- `jester_card_art.png`

These crops are extracted from the generated visual concept. They are usable as portrait/card artwork placeholders, but are not yet clean isolated illustrations: some original decorative frame/background pixels may remain.

## Important
The UI must remain built from Compose controls and live game data. Do not use `premium_ui_art_direction.png` as a flattened screen background. The reference image is included only to guide future layout and styling.

The current pack does not yet include a clean standalone castle background, table texture, complete 52-card deck artwork, or all UI ornaments. Those need separately generated/exported assets before claiming a pixel-matched final UI.
